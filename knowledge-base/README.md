# Knowledge base — RAG corpus (draft)

Raw source documents for the RAG pipeline. Each file is one "document" that gets
chunked, embedded, and indexed (see plan, days 6-7).

**These are AI-drafted skeletons, not finished content.** They lay out correct,
plausible technical reasoning based on the skills listed in the project's "About
me" doc, but they do **not** contain your real project names, real numbers, or
real specifics — those are marked with `[TODO: ...]`. Fill those in with your
actual experience before treating this as ground truth for interview answers;
an AI-invented specific you repeat as fact is a risk, not a shortcut.

Suggested edit pass per file: replace every `[TODO: ...]`, cut anything that
doesn't match what you actually did, and don't be afraid to make it shorter and
more specific rather than longer and more general — specific beats generic for
retrieval quality too (closer wording to how you'll actually ask questions).
